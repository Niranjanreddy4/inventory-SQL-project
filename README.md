# Inventory Management SQL Project

A MySQL database project that manages products, categories, and sales 
for a small store — with queries to answer real business questions.

## What it includes
- 3 related tables: categories, products, orders (with foreign keys)
- Sample data for testing
- Queries covering: SELECT, WHERE, JOIN, GROUP BY, aggregate functions

## Key queries
- View products with category names (JOIN)
- Find low-stock products (WHERE)
- Total units sold per product (GROUP BY + SUM)
- Total revenue per category (JOIN + GROUP BY + calculation)

## Tool used
MySQL Workbench

## Skills demonstrated
- Relational database design (primary keys, foreign keys)
- SQL querying: JOIN, GROUP BY, WHERE, aggregate functions
